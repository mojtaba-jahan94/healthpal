برای دریافت زنده گام‌ها از اکانت گوگل خود بدون نیاز به سرور واسط، مراحل زیر را یک‌بار انجام دهید:

  1. به Google Cloud Console بروید و یک پروژه رایگان بسازید.
  2. از منوی APIs & Services، گزینه Fitness API را جستجو و روی Enable کلیک کنید.
  3. در بخش Credentials، روی Create Credentials و سپس OAuth Client ID (نوع Web Application) بزنید.
  4. آدرس دامنه یا http://localhost را در قسمت Authorized JavaScript origins قرار دهید.
  5. شناسه تولید شده (Client ID) را کپی کرده و در تب پروفایل > تنظیمات Google Client ID در همین برنامه وارد کنید.

نکته: در صورت تمایل، می‌توانید فعالیت‌ها و گام‌های خود را به صورت دستی نیز با دکمه «ثبت ورزش» وارد نمایید.
