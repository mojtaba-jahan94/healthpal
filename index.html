راهنمای اتصال به Google Fit

برای دریافت زنده گام‌ها از اکانت گوگل خود بدون نیاز به سرور واسط:

  1. وارد Google Cloud Console شوید.
  2. از منوی APIs & Services، سرویس Fitness API را فعال کنید.
  3. در بخش Credentials یک OAuth Client ID (نوع Web Application) بسازید.
  4. شناسه تولید شده (Client ID) را در بخش تنظیمات وارد نمایید.

همچنین می‌توانید در صورت تمایل گام‌ها و ورزش‌های خود را به صورت دستی ثبت کنید.
