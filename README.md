# HealthPal - مدیریت سلامت، کالری‌شمار و ورزش (مشابه MyFitnessPal)

یک اپلیکیشن پیش‌رونده (**PWA**) مدرن، زیبا و سبک برای مدیریت هوشمند کالری روزانه، درشت‌مغذی‌ها، ورزش، مصرف آب و پیشرفت وزن.

---

## ویژگی‌های اصلی

- **دستیار هوش مصنوعی Google Gemini (استعلام خودکار غذاها):**
  اگر نام هر غذا، سالاد، معجون یا دسر دلخواهی (حتی محلی یا ترکیبی) را در کادر جستجو تایپ کنید، جمینای با یک کلیک مشخصات دقیق کالری، پروتئین، کربوهیدرات، چربی و سهم استاندارد آن را استخراج می‌کند و به طور خودکار در دیتابیس لوکال ذخیره می‌کند تا دفعات بعدی کاملاً آفلاین در دسترستان باشد!
- **معادله کالری مشابه MyFitnessPal:**
  `کالری هدف - غذای مصرف شده + کالری ورزش = کالری باقی‌مانده`
- **تفکیک درشت‌مغذی‌ها (Macros):**
  محاسبه و نمایش گرم و درصد کربوهیدرات، پروتئین و چربی همراه با نوارهای پیشرفت رنگی.
- **بانک جامع غذاهای ایرانی و بین‌المللی:**
  شامل نان‌های سنتی (سنگک، بربری، لواش)، پلوها و خورشت‌های ایرانی (قورمه‌سبزی، قیمه، چلوکباب، زرشک‌پلو، عدسی...)، پروتئین‌ها، لبنیات، میوه‌ها و آجیل.
- **امکان تعریف غذای سفارشی:**
  افزودن نامحدود غذاهای شخصی به بانک اطلاعاتی لوکال.
- **ذخیره‌سازی ۱۰۰٪ محلی و آفلاین (Offline-First):**
  استفاده از پایگاه داده استاندارد **IndexedDB** درون مرورگر کاربر بدون نیاز به هیچ سرور خارجی. حریم خصوصی کامل و دسترسی همیشگی بدون اینترنت.
- **پشتیبان‌گیری و بازیابی (Backup & Restore):**
  امکان دانلود فایل نسخه پشتیبان JSON و بازیابی آن جهت انتقال اطلاعات بین گوشی و لپ‌تاپ.
- **ردیاب آب و گام‌شمار:**
  شمارنده تصویری لیوان‌های آب و ثبت ورزش‌های هوازی و قدرتی.
- **نمودار تعاملی وزن و شاخص BMI:**
  ثبت وزن دوره‌ای و رسم نمودار پیشرفت خطی.
- **محاسبه‌گر خودکار BMR و TDEE:**
  فرمول استاندارد Mifflin-St Jeor برای تعیین کالری متناسب با قد، وزن، سن و هدف (کاهش، تثبیت یا افزایش وزن).
- **اتصال به Google Health / Google Fit:**
  قابلیت دریافت مستقیم گام‌ها و کالری سوزانده شده از طریق اکانت گوگل (با OAuth 2.0).
- **نصب روی گوشی‌های اندروید و دسکتاپ (PWA):**
  قابلیت Install App و قرارگیری به عنوان اپ بومی روی صفحه اصلی گوشی.

## نحوه اجرا در ویندوز (دسکتاپ)

کافی است روی فایل `run.bat` دوبار کلیک کنید:
1. سرور لوکال سبک بدون هیچ نیازی به نصب Node.js یا نرم‌افزار جانبی اجرا می‌شود.
2. مرورگر پیش‌فرض شما به صورت خودکار با آدرس `http://localhost:8080/` باز می‌شود.
3. در آدرس‌بار مرورگر (Chrome یا Edge) می‌توانید آیکون **Install App** را بزنید تا برنامه مانند یک نرم‌افزار مستقل دسکتاپ روی ویندوز نصب شود.

## نحوه استفاده و نصب روی گوشی اندروید

### روش ۱: شبکه محلی (وای‌فای مشترک با کامپیوتر)
1. کامپیوتر و گوشی را به یک شبکه وای‌فای متصل کنید.
2. هنگام اجرای `run.bat`، آدرس شبکه محلی (مانند `http://192.168.1.X:8080`) در کنسول نمایش داده می‌شود.
3. آن آدرس را در مرورگر کروم گوشی خود وارد کنید.
4. منوی ۳ نقطه مرورگر را بزنید و گزینه **Install App** یا **Add to Home screen** را انتخاب کنید.

### روش ۲: میزبانی رایگان روی GitHub Pages یا Vercel (توصیه شده)
چون این برنامه یک Single-Page Web App بدون نیاز به سرور است:
1. پوشه پروژه را در یک ریپازیتوری GitHub آپلود کنید.
2. از بخش Settings > Pages گزینه GitHub Pages را فعال کنید.
3. آدرس HTTPS اختصاصی شما ساخته می‌شود. با باز کردن آن در هر گوشی اندرویدی، بنر نصب اپلیکیشن به صورت وب‌اپلیکیشن تمام‌صفحه با آیکون ظاهر می‌شود.

## اتصال به Google Fit API

1. وارد [Google Cloud Console](https://console.cloud.google.com/) شوید و یک پروژه بسازید.
2. از بخش **APIs & Services > Library**، سرویس **Fitness API** را فعال کنید.
3. در بخش **Credentials**، یک **OAuth Client ID** از نوع Web Application بسازید و آدرس دامنه خود را در Authorized JavaScript origins اضافه کنید.
4. شناسه Client ID را در بخش **پروفایل > تنظیمات Google Client ID** وارد کرده و دکمه اتصال را بزنید.
